# Grazie Restaurant

Modern rebuild of [grazie-restaurant.com](http://www.grazie-restaurant.com/) for Grazie Restaurant in Novato, CA - a family-run Italian-American bistro on Grant Avenue since 1998.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS + shadcn/ui

## Local development

```bash
npm install
npm run dev
```

App runs on [http://127.0.0.1:43171](http://127.0.0.1:43171).

## Deploy

```bash
# Ensure you are logged in: npx vercel login
npx vercel@latest deploy --prod --yes
```

## Source facts

Contact, hours, menu sections, reviews, and photography are taken from the live Homestead site and related public listings. Brand logo and food photos are original Grazie assets.
